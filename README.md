# NHS Data Portfolio

A collection of data analysis projects using real NHS and UK healthcare datasets, 
built while working toward NHS Data Scientist / Healthcare Analyst roles.

## Projects

### [Project 1: NHS A&E Admissions Analysis](./project-01-ae-admissions)
Analysis of NHS England A&E attendance and admission data across 192 Trusts (May–June 
2026 comparison). Key findings include a persistent structural wait-time pattern at one 
Trust verified across two months, a strong correlation between admission rate and 
4-hour wait breaches, and several Trusts showing sharp month-over-month deterioration.

**Tools:** Python, pandas, matplotlib
