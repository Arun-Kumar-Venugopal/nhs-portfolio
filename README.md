# NHS Data Portfolio

A collection of data analysis projects using real NHS and UK healthcare datasets, 
built while working toward NHS Data Scientist / Healthcare Analyst roles.

## Projects

### [Project 1: NHS A&E Admissions Analysis](./project-01-ae-admissions)
Analysis of NHS England A&E attendance and admission data across 192 Trusts. 
Key findings include a strong correlation between admission rate and 4-hour wait 
breaches, a significant outlier Trust, and a regional performance comparison.

**Tools:** Python, pandas, matplotlib
